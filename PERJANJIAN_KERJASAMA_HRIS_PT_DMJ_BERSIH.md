3. **Ketentuan Biaya Cloud Running Apps (Tipe Shared Environment), Batas Kapasitas User & Alokasi Kuota Storage:**
   - **a. Biaya Berlangganan Dasar & Tipe Server (Shared Environment):**  
     Untuk menjamin keandalan server cloud 24/7, proteksi SSL Cloudflare, dan auto-backup harian, PIHAK KEDUA dikenakan biaya langganan dasar server sebesar **Rp 35.000,- (Tiga Puluh Lima Ribu Rupiah) per bulan**, yang ditagihkan secara berkala terhitung sejak bulan kedua setelah sistem Go-Live resmi. Arsitektur lingkungan server *running apps* yang digunakan pada paket dasar ini adalah **bertipe *SHARED* (Shared Cloud Server Environment)**, di mana alokasi *resource* komputasi dioptimasi bersama secara efisien dan ekonomis.
   - **b. Batas Kapasitas User & Skalabilitas Performa:**  
     Biaya dasar Rp 35.000,-/bulan dengan arsitektur *shared server* tersebut dioptimasi secara ideal untuk kapasitas **50 hingga 100 user/karyawan aktif**. Apabila di kemudian hari jumlah karyawan bertambah melampaui 100 user aktif, atau apabila dirasa performa server kurang mencukupi seiring tingginya aktivitas presensi bersamaan, PIHAK KEDUA dapat mengajukan penambahan kapasitas server (upgrade RAM, CPU, atau bandwidth komputasi) maupun beralih ke *Dedicated Server Environment* dengan biaya penyesuaian tersendiri.
   - **c. Alokasi Kuota Penyimpanan (Storage):**  
     Paket dasar ini telah menyertakan alokasi ruang penyimpanan sebesar **1 GB Storage Aktif** (untuk operasional aplikasi dan basis data harian) serta **10 GB Dedicated Storage** khusus untuk cadangan data otomatis berkala.
   - **d. Penambahan Kuota Penyimpanan di Luar Kontrak:**  
     Apabila kapasitas penyimpanan aktif atau cadangan tersebut dirasa kurang atau hampir penuh seiring bertambahnya akumulasi data foto presensi, penambahan kapasitas penyimpanan (*storage expansion*) dapat ditambahkan sebagai layanan add-on berbayar di luar nilai kontrak pokok proyek ini.
   - **e. Ketentuan Penyesuaian Tarif & Alternatif Solusi Pengakhiran Layanan (Exit Policy):**
     - **(1) Penyesuaian Biaya Sewaktu-Waktu:**  
       Besaran biaya langganan cloud running apps bulanan maupun tarif layanan add-on (penambahan kuota storage, upgrade kapasitas user/server, migrasi dari tipe shared ke dedicated, dan modul kustom) dapat sewaktu-waktu mengalami penyesuaian oleh PIHAK PERTAMA mengikuti kenaikan biaya infrastruktur datacenter/cloud provider internasional, beban komputasi, inflasi, atau fluktuasi kurs valuta asing, dengan pemberitahuan tertulis kepada PIHAK KEDUA selambat-lambatnya **30 (tiga puluh) hari kalender** sebelum tarif penyesuaian diberlakukan secara efektif.
     - **(2) Pemberian Alternatif Solusi Apabila Klien Tidak Melanjutkan:**  
       Apabila PIHAK KEDUA keberatan atau memutuskan untuk tidak melanjutkan langganan server cloud / add-on atas dasar penyesuaian tarif tersebut, PIHAK PERTAMA memberikan alternatif solusi yang adil dan aman tanpa pengenaan denda/penalti, yaitu:
       - **• Opsi Beralih ke Mode Offline Mandiri (.exe):** PIHAK KEDUA dapat menjalankan dan mengoperasikan sistem sepenuhnya secara lokal di komputer/jaringan kantor PT DMJ menggunakan paket aplikasi offline portable (`.exe`) dan basis data lokal mandiri yang telah diserahkan pada BAST, sepenuhnya bebas dari biaya langganan bulanan selamanya.
       - **• Opsi Migrasi ke Server / Cloud Mandiri (Self-Hosted):** PIHAK KEDUA berhak memindahkan instalasi sistem ke server fisik kantor atau akun cloud/hosting milik PIHAK KEDUA sendiri, di mana PIHAK PERTAMA akan memfasilitasi penyerahan file cadangan (*database backup*) secara utuh.
       - **• Terminasi Layanan & Serah Terima Data Lengkap (Safe Data Handover):** PIHAK PERTAMA menjamin seluruh data historis karyawan, rekapitulasi presensi, dan data slip gaji akan diekspor dan diserahkan seutuhnya kepada PIHAK KEDUA sebelum instance server cloud dinonaktifkan secara resmi.

   Ruang lingkup pekerjaan yang mengikat PIHAK PERTAMA adalah fitur-fitur yang tercantum secara eksplisit pada **Pasal 1**.    - a. PIHAK KEDUA wajib mengajukan permohonan tertulis melalui **Formulir Permintaan Perubahan (Change Request Form)**.
   - b. Dalam waktu maksimal **3 (tiga) hari kerja**, PIHAK PERTAMA menerbitkan dokumen analisis dampak teknis, estimasi hari kerja teknis (*Man-Days*), penawaran biaya, dan pergeseran jadwal delivery.

   Penyesuaian dan penambahan fitur diklasifikasikan ke dalam 3 (tiga) kategori berikut:

### TABEL KLASIFIKASI CHANGE REQUEST (CR)

| Kategori | Ruang Lingkup Fitur / Pekerjaan | Biaya & Kompensasi | Dampak Timeline |
| :---: | :--- | :--- | :--- |
